# Spec — 建立公司資訊(名稱 + 統一編號)CRUD(Issue #1)

## 來源

- Intent:#1
- 串接第三方單位:無

## 需求描述

1. 業務人員可以新增一筆公司資料,至少包含「公司名稱」與「統一編號」兩個欄位。
2. 業務人員可以查詢(列表 / 依條件查詢)已建立的公司資料。
3. 業務人員可以修改既有公司資料的「公司名稱」與「統一編號」。
4. 業務人員可以刪除既有公司資料。

## 驗收條件(Acceptance Criteria)

- [ ] AC1:Given 業務人員在新增公司資料頁面,When 輸入公司名稱與統一編號並送出,
      Then 系統成功建立一筆公司資料並可在列表中看到。
- [ ] AC2:Given 系統中已有公司資料,When 業務人員查詢,Then 能看到該筆資料的
      公司名稱與統一編號。
- [ ] AC3:Given 系統中已有一筆公司資料,When 業務人員修改其公司名稱或統一編號並
      送出,Then 該筆資料被更新且查詢時顯示新值。
- [ ] AC4:Given 系統中已有一筆公司資料,When 業務人員執行刪除,Then 該筆資料不再
      出現在查詢結果中。

## 範圍外(Out of Scope)

- 公司資料以外的其他客戶相關欄位(如聯絡人、地址、產業別等)不在本次範圍。
- 權限控管(哪些角色可以新增/修改/刪除)不在本次範圍。
- 統一編號格式驗證與重複資料防呆邏輯不在本次範圍(見下方開放問題)。
