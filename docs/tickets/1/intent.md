# Intent — 建立公司資訊(名稱 + 統一編號)CRUD

Ticket: #1 — https://github.com/DCMA/CRM_TEST/issues/1

## 問題 / 背景

目前業務團隊完全沒有系統可以記錄客戶公司的基本資料(名稱、統一編號)。業務人員
每次接觸新客戶時都需要用到這筆資料,但目前沒有集中存放的地方,導致客戶資料分散、
難以查詢。

## 期望結果

業務人員能在系統裡集中新增、查詢、修改、刪除公司資料(名稱 + 統一編號)。

成功標準:能成功新增、查詢、修改、刪除一筆公司資料(名稱 + 統一編號)即算完成。

## 影響的使用者與系統

- 使用者:業務人員(主要使用者)
- 系統:不碰到外部系統(無 SAP/ERP 等對接)

## 限制條件

無特別限制。

## 開放問題

無 — 目前都已確定。
